# SRG Warehouse Stock

A shared, phone-friendly warehouse inventory app: photograph stock, assign bin
locations, and book items in and out with a full movement log.

`index.html` is the whole app. It's published as a Claude artifact and uses
Claude's artifact runtime for its shared database (`items`, `moves`),
photo storage, user names and CSV export, so it won't load data when opened
as a plain local file.

Live app: https://claude.ai/artifact/9GEMvnaS92BVBgTgA78YYc
